# Implementation Plan: Visit & Transaction Model Restructuring (P1-T4)

## Summary

Restructure the `Visit` and `Transaction` models in `visits/models.py` to enforce FinTech-grade immutability, correct FK deletion protection, and proper escrow ledger behavior. Add `distance_km` and `distance_rate` pricing fields. Restructure `Transaction` with agency FK, Paymob gateway fields, auto-calculated `agency_payout`, and simplified three-state lifecycle (`ESCROWED`/`SETTLED`/`REFUNDED`). Update admin registrations with financial field protection and GIS map widget for agencies.

## Proposed Changes

### Component 1: Visit Model (`visits/models.py`)

#### [MODIFY] [models.py](file:///d:/projects/Wateen/visits/models.py)

1. **FK changes**: `agency` and `nurse` ForeignKeys change `on_delete` from `SET_NULL` to `PROTECT`
2. **New fields**: Add `distance_km` (DecimalField 6,2) and `distance_rate` (DecimalField 10,2) after existing pricing fields
3. **Immutability**: Add `save()` override with `IMMUTABLE_PRICING_FIELDS` constant listing: `base_price`, `distance_fee`, `distance_km`, `distance_rate`, `time_multiplier`, `ai_surge_coefficient`, `final_price`. On update, compare each field against DB values; raise `ValidationError` if changed.

---

### Component 2: Transaction Model (`visits/models.py`)

#### [MODIFY] [models.py](file:///d:/projects/Wateen/visits/models.py)

1. **TransactionStatus**: Remove `PENDING` and `FAILED`, keep `ESCROWED`, `SETTLED`, `REFUNDED`. Default to `ESCROWED`.
2. **Field renames** (via migration):
   - `total_amount` → `amount_paid`
   - `take_rate_percent` → `wateen_take_rate`
   - `agency_amount` → `agency_payout` (add `editable=False`)
   - `stripe_payment_intent_id` → `paymob_order_id`
3. **Remove**: `take_rate_amount` field (redundant with auto-calculation)
4. **New fields**: `agency` FK (PROTECT), `paymob_transaction_id` CharField, `settled_at` DateTimeField
5. **FK change**: `visit` OneToOneField `on_delete` from `CASCADE` to `PROTECT`
6. **save() override**: Auto-calculate `agency_payout = amount_paid * Decimal('0.85')`. Auto-set `settled_at = timezone.now()` when status → `SETTLED`.
7. **Remove**: `clean()` method and `calculate_split()` method (replaced by `save()` auto-calc)

> [!WARNING]
> The user's plan at `plans/visit-transaction-restructure-plan.md` line 175 uses `models.Column(...)` which is NOT a valid Django construct. The correct syntax is `models.CharField(...)` directly (not wrapped in `Column`).

---
